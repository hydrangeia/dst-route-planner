# DST 大陆路线规划

[English](README.en.md)

想在《饥荒联机版》里找排箫、猪王或月台？轻量客户端采集器读取玩家坐标和周围地皮、地标，外置 Python 网页随着观测更新探索方向。也可以手动录入线索，载入示例或复用一局的探索记录。

## 开始使用

需要 Python 3.10 或更新版本。克隆仓库后，在仓库目录启动本地网页：

```powershell
git clone https://github.com/hydrangeia/dst-route-planner.git
cd dst-route-planner
python route_planner.py --ui
```

Windows 用户也可以双击 `start_planner.bat` 启动。页面在本机浏览器打开。

## 连接实时观测

先把仓库中的 [`mods/dst_route_collector`](mods/dst_route_collector/README.md) 安装到游戏的 `mods/` 目录。目录需要已存在；Windows 用户可在仓库目录运行：

```powershell
python route_planner.py --install-collector "D:\SteamLibrary\steamapps\common\Don't Starve Together\mods"
```

把示例路径换成游戏实际的 `mods/` 目录。也可以按采集器说明手动复制整个文件夹。安装后，在游戏的客户端模组列表启用 DST Route Planner Live Collector 并进入一个世界。工具启动时会自动定位客户端日志；Windows 用户直接双击 `start_planner.bat`，或运行：

```powershell
python route_planner.py --ui
```

在网页点“检查连接”，查看正在读取的文件和下一步提示；勾选“实时跟随”可在网页显示实时位置和导航建议。工具运行期间会自动在后台记录新快照；如果日志一次刷出多份新快照，后台会按日志顺序逐帧记录。采集器每秒提供坐标和周围线索，页面自动计算方向，看到目标时显示直线距离。移动一下，确认坐标跟着变化，就可以开始探索。

也可以在终端单独检查连接：

```powershell
python route_planner.py --check-live
```

日志存放在其他位置时，用 `--live-log "实际路径/client_log.txt"` 指定文件。`--live-log auto` 与默认的自动定位相同。手动录入时保持“实时跟随”未勾选即可。

方向使用固定世界坐标：北为 `+Z`，东为 `+X`。地图默认显示全部已观测区域。点“全图”恢复全图视野；点“跟随位置”让局部视野随最新位置移动；“放大”和“缩小”调整视野范围。

在轨迹图上选择“路线终点”，或点击一格已观测且可通行的地皮。工具沿已检查通过的相邻格连接查找最少步数路线。使用 0.5.0 采集器时，还会检查玩家当前位置到所在格中心的一段；通过后，路线从实际玩家位置出发，显示总距离和下一步的方向与坐标。接入段受阻时会提示，旧数据仍可查看格中心路线。玩家移动或收到新检查时自动重算，历史回放也能查看。图中终点是所选格的中心，格网每步为 4 个世界单位。没有路径时显示“未连通”；切换世界或采集会话时清空终点。

实时跟随期间，采集暂停、出错、手动停止，或最后有效快照超过五秒时，地图会显示“导航已暂停”，隐藏紫色实时路线和下一步提示；已观测地皮、最后轨迹位置、路线终点及来源目标保留。实时请求五秒未完成会超时；超时后等待一秒再重试；收到新鲜快照后自动恢复，无需手动重新勾选。历史回放仍按记录显示路线。

工具运行期间会在后台把新快照保存在本机 JSONL 中，包含坐标、周围线索、当前目标和当时的方向建议。在“探索回放”中可下载记录；重启后仍可下载已有回放。关闭网页、查看历史或取消实时跟随都不会中断录制；退出 Python 工具（终端按 Ctrl+C）后录制结束。不同世界和采集会话分别记录。

“探索轨迹”会随着实时位置更新，标出起点和最新位置。点击已保存回放旁的“查看轨迹”，或打开导入回放，都可以回看轨迹；查看历史回放会暂停实时跟随，重新勾选后回到当前会话。打开历史回放（包括导入回放）默认停在最新观测帧；用“回放进度”“上一帧”“下一帧”逐帧回看，或点“跳到最新”。每帧只显示当时已观测的位置、地皮、连接和目标。实时跟随时历史控件隐藏，后台录制照常继续。

在“探索回放”区域点“导入回放”会打开文件对话框，选择工具下载的 JSONL 后自动上传。上传成功且当前视图未改变时，页面会自动打开导入轨迹；如果上传期间切换了视图或世界，当前视图会保留，也可以点“查看导入轨迹”手动打开。导入轨迹包含位置、地皮、已见目标和格网路线。图上北为 `+Z`、东为 `+X`，采集中断或坐标跳变处会断开连线。

轨迹图还会标出所选目标曾被看到的位置。“已见目标”列出最近 10 条记录的时间、坐标，以及相对最新玩家观测的方向和直线距离。切换目标即可回看对应地标；重新打开历史回放时也能查看。标记记录的是看到它时的位置，移动或被采集的目标可能已不在原处。在列表中点“前往所在格”，或直接点地图菱形，可将记录位置所在且已观测可通行的地皮格设为路线终点；路线会显示来源目标，并到达该格中心。

“显示已观测地皮”会把采集到的地皮铺在轨迹下方，用颜色区分草地、森林、岩地、沼泽、水域和其他地皮。走动时底图逐步补充，回放也会保留；空白处表示尚未采集。洞穴也支持坐标、轨迹和地皮记录，方向推理还待接入。斜线标出格中心地形检查不通过的位置；指向色块可查看通行状态，未采集的状态显示为未知。关闭开关可以只看轨迹与目标。更新已有采集器时，可再次运行上面的安装命令，或按采集器说明手动复制，然后重新进入世界。

勾选“显示邻格检查”，可以查看已观测相邻格之间的直连关系。图例区分检查通过与受阻，实时地图和历史回放都能查看；没有检查结果的连接留空。

## 手动录入与保存

1. 选择要找的目标。
2. 在各个方向填写看到的地皮、prefab 和数量。
3. 点击“计算方向”，查看方向排名及对应线索。
4. 回到 DST 探索并保存；下次启动时从记录列表打开本局，继续补充和保存观测。

界面提供示例数据，也可以导入或导出 JSON 观测。还可以填写记录名称和世界备注后点“保存”，或点“另存为新记录”保留一份副本。重启工具后，或在同一仓库目录下换浏览器或端口，都可以从记录列表打开本局、补充观测并再次保存。JSON 观测的导入和导出仍使用原来的格式。

每次保存都会更新这条记录的当前观测；修改后再点“保存”即可。

```text
安装采集器 → 在游戏客户端模组列表启用并进入世界 → 启动工具，自动定位日志
  ↓
检查连接 → 选择目标，实时采集坐标、地皮、地标与地形通行状态（每秒）
  ↓
采集器：检查玩家位置到所在格中心，以及相邻已观测格之间的连接
  ↓
客户端日志 → Python 后台按日志顺序逐帧记录，并更新位置与方向建议
  ↓
知识库匹配 room / task，结合连接图排列探索方向
  ↓
网页自动更新建议；目标可见时显示直线距离
  ↓
已见目标列表或地图菱形 → 前往所在格 → 设为路线终点
  ↓
根据玩家当前位置计算路线并显示下一步
  ↓
玩家移动或出现新连接检查 → 自动更新路线
  ↓
采集暂停 / 出错 / 手动停止 / 快照过期 → 暂停；请求超时 → 等待一秒后重试；新鲜快照 → 恢复（停止或历史回放时不重试）
  ↓
新快照 → 本机探索回放 → 网页展示轨迹与路线（可选全图 / 跟随位置），叠加已观测地皮、最新位置与已见目标
  ↓
历史回放 → 查看轨迹和路线 → 进度滑块 / 前后帧 → 回看当时已观测内容
  ↓
下载 JSONL → 导入回放 → 查看轨迹和路线
  ↓
玩家继续移动 → 再次采集、计算和更新
  ↓
保存当前观测与世界备注，下次继续探索
```

## 当前进度

本地 Python 引擎结合默认大陆的 20 个 task、53 个 room、13 个静态布局和 20 种目标线索来排列方向。任务连接图描述世界生成中的拓扑关系，自动采集或手动填写的地皮与地标提供眼前的线索。命名记录把目标、世界备注和当前观测保存在本机，方便玩家重启后接着探索。
